LLM INSTRUCTIONS FOR COMPACT TIMER URL FORMAT

Goal:
- Output a compact routine string for the `x` URL parameter
- Preserve full spoken labels for text-to-speech
- Do not output JSON unless explicitly asked


OUTPUT FORMAT

Return only the compact routine string unless asked for explanation.

Structure:

Routine Name~Label Section 1~Pattern 1~Label Section 2~Pattern 2~...


LABEL SECTION RULES

- `Work Label`
  Use this when the prepare cue and work label are the same.

- `Work Label^Prepare Label`
  Use this when the prepare spoken cue should be different from the work label.

Examples:

- `4-finger half crimp`
- `Front-2 open^Front-2 open, index and middle`


PATTERN RULES

- `p5` = prepare for 5 seconds
- `w10` = work for 10 seconds
- `r20` = rest for 20 seconds
- `r10!` = final rest for 10 seconds, marked `skip_on_last`

Patterns are comma-separated.

Example:

`p5,w10,r20,w10,r20,w10`


IMPORTANT LIMITATION

Do not use compressed repeat notation like `r20x5`.

The current parser expects each repeated block explicitly written out.

Use this:

`p5,w10,r20,w10,r20,w10,r20,w10`

Not this:

`p5,w10,r20x3,w10`


COUNTDOWN

Countdown is passed separately in the URL with `cd`.

Example:

`&cd=3`

Unless told otherwise, assume:

- `cd=3` for hang-style timers
- longer countdowns only when explicitly requested


FULL URL SHAPE

`https://something.com/?x=<compact-routine>&cd=3`
