COMPACT FORMAT LEGEND

- `~` separates sections
- `^` separates work label from prepare label override
- `p5` = prepare 5 seconds
- `w10` = work 10 seconds
- `r20` = rest 20 seconds
- `r20x5,w10` = repeat "rest 20 + work 10" five more times after the first work
- `cd=3` = apply `countdown_last: 3` to all work blocks


WHY THE AFTER VERSION IS SHORTER

- It keeps all spoken labels
- It removes repeated JSON keys
- It removes repeated object punctuation
- It removes repeated `countdown_last` entries from every work block
- It compresses repeated work/rest sequences into short pattern notation
